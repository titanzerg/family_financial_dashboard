# Family Finance Dashboard — Module 1 (สรุปสินทรัพย์รายเดือน)

ทำตาม [spec.md](spec.md) — บันทึกยอดคงเหลือสิ้นเดือนของแต่ละบัญชี, รวมยอด, เทียบกับเดือนก่อนหน้า และแดชบอร์ด

## วิธีรัน

ต้องมีแค่ Python 3.10+ (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
python3 server.py
# เปิด http://127.0.0.1:8765
```

- ข้อมูลเก็บที่ `data/finance.sqlite` (เปลี่ยนได้ด้วย `FINANCE_DB=...`, พอร์ตด้วย `FINANCE_PORT=...`)
- ไฟล์สำรองอัตโนมัติอยู่ที่ `data/backups/` — สำรองวันละครั้งตอนเปิดโปรแกรม, ก่อนย้ายกลุ่ม/ปิดใช้งานบัญชี และก่อนกู้คืนข้อมูล
- เซิร์ฟเวอร์รับการเชื่อมต่อจากเครื่องตัวเองเท่านั้น (127.0.0.1)

รันเทสต์: `python3 -m unittest discover -s tests`

## การใช้งานโดยย่อ

1. **จัดการบัญชี** — เพิ่มบัญชีลง 4 กลุ่ม (A ค่าใช้จ่าย/เงินกันไว้, B เงินฝาก, C ลงทุน, D สำรองโปะบ้าน), เปลี่ยนชื่อ, ย้ายกลุ่ม, เรียงลำดับ, ปิดใช้งาน
2. **ตารางรายเดือน** — เพิ่มเดือน แล้วกรอกยอดสิ้นเดือน (Enter/↓ ไปช่องถัดไป, Esc ยกเลิก, คลิกขวาเพื่อใส่หมายเหตุ)
3. **แดชบอร์ด** — ยอดรวม, การเปลี่ยนแปลงเทียบเดือนก่อน (ระบุเดือนที่เทียบเสมอ), แยกตามกลุ่ม, เงินสำรองโปะบ้าน, แนวโน้ม
4. **สำรอง / ส่งออก** — CSV (เปิดใน Excel ได้), JSON สำรองครบชุด, กู้คืน, ประวัติการแก้ไข

## การตัดสินใจในการออกแบบ (ข้อที่ spec เปิดไว้)

| เรื่อง | ที่ทำไว้ | 
|---|---|
| ช่องว่าง vs 0 | ช่องว่าง = ยังไม่บันทึก ไม่นับเป็น 0; ต้องพิมพ์ 0 เองถ้ายอดเป็นศูนย์จริง |
| ก่อนเริ่มใช้บัญชี | เดือนก่อนยอดแรกของบัญชีแสดงเป็น "ยังไม่มี" ไม่นับว่าขาด |
| บัญชีที่อัปเดตไม่บ่อย (กลุ่ม C) | ตอนเพิ่มเดือนเลือก "ยกยอด" ได้ — ยอดจะมีเครื่องหมาย ↻ และแสดงเดือนที่อัปเดตมูลค่าล่าสุด จนกว่าจะพิมพ์ยอดจริง (พิมพ์ค่าเดิมซ้ำ = ยืนยัน) |
| เดือนก่อนหน้า | เดือนล่าสุดก่อนหน้าที่มียอดบันทึก (ข้ามเดือนว่าง) และแสดงชื่อเดือนที่ใช้เทียบเสมอ |
| หนี้สิน/บัตรเครดิต | รับยอดติดลบได้ ยังไม่แยกประเภทหนี้ (รอยืนยันจาก workbook จริง) |
| ความแม่นยำ | เก็บเป็นสตางค์ (จำนวนเต็ม) ทศนิยมได้ไม่เกิน 2 ตำแหน่ง |
| การแก้ไข | ทุกการเปลี่ยนแปลงถูกบันทึกใน `audit_log` พร้อมค่าเดิม; ลบเดือนได้เฉพาะเดือนว่าง |

ยังไม่ได้ทำ: นำเข้าจาก Excel เดิม (spec ข้อ 11 — รอดูไฟล์จริง)

## โครงสร้าง

```
server.py          HTTP server + JSON API (stdlib)
finance/core.py    schema/migration, validation, การคำนวณ, export/backup/restore
static/            หน้าเว็บ (HTML/CSS/JS ไม่ใช้ framework)
tests/             unit tests ตาม acceptance criteria
```

**สำหรับ Module 2/3 ในอนาคต:** เพิ่มตารางใหม่ผ่าน migration ใน `core.migrate()` (ใช้ `PRAGMA user_version`)
และอ้างอิง `accounts.id` / `balances(account_id, period)` — ห้ามเปลี่ยนความหมายของยอดรวมและส่วนต่างรายเดือน
ทดสอบ migration กับสำเนาข้อมูลจริงก่อนใช้งานเสมอ
